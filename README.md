# Norte

Um copiloto adaptativo para fazer o que importa caber no seu dia.

## Princípio

O Norte é um agente de suporte executivo: observa contexto, ajuda a priorizar, pergunta quando precisa de informação, toma pequenas decisões reversíveis e aprende com o uso.

## Stack inicial

React + TypeScript + Vite + Tailwind CSS + GitHub Pages.

O núcleo deve funcionar sem depender de APIs pagas de IA.
